# 进阶练习储备

先完成入门短片，再按遇到的问题选择一项。这里是候选练习，不是已交付的完整课程，也不需要一次全部安装。

| 入门后遇到的问题 | 可以做的练习 | 要看见的结果 |
|---|---|---|
| 每次都重写相似动画 | 从 wise-motion 选一个动作，替换允许的内容并接入独立工程 | 原效果与新主题都能正确导出，记录依赖与修改范围 |
| 下一条片又走回同样的弯路 | 将已经跨主题验证的镜头整理为方法包，再编写客户端 Skill 入口 | 在新目录中仅凭交付材料能完成调用 |
| 旁白剪得不自然 | 对一小段自己录制的口播做剪辑决定表，保留呼吸并逐个听审接缝 | 语义完整、停顿自然；改剪点不重复转录 |
| 画面与声音各走各的 | 用同一时间线对齐动作、字幕和声音 | 跳转定位与最终导出仍然同步 |
| 模板装不下空间关系 | 给一个具体镜头增加 Three.js 或 Blender | 相机、遮挡、尺度确实帮助理解，保留可编辑场景 |

进阶应围绕“同一镜头如何更稳、更好改”展开，避免变成工具列表。新工具有明确用途时再引入。
