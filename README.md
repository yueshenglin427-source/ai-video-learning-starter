# 用 AI 做出第一段可修改的视频

从一个能打开、能修改的短镜头开始，学会描述动作、预览、局部修订和导出，再把好用的方法留下来。

这里提供入门练习、任务模板、原创网页动效和精选项目入口。适合已经能使用 AI 编码工具读写本地文件、但还没有视频工程经验的人。不会写代码也可以跟着练习；你仍需要判断画面是否清楚、节奏是否合适。

## 从这里开始

1. 下载仓库：GitHub 页面点击 **Code → Download ZIP** 并解压；会用 Git 也可以克隆。
2. 用浏览器打开 [聊天动效示例](examples/chat-motion/demo.html)。下载到本机后打开 HTML；GitHub 文件页本身不会播放示例。
3. 跟着 [入门练习](docs/BEGINNER.md)，改内容、改节奏，再完成一次局部修订。
4. 需要 MP4 时，按 [运行与导出](QUICKSTART.md)选择一条视频框架。

网页示例可以播放、暂停和拖动定位，不需要 npm、模型账号或 API 密钥。它没有内置 MP4 导出按钮。

```bash
git clone https://github.com/yueshenglin427-source/ai-video-learning-starter.git
cd ai-video-learning-starter
```

## 工具分别做什么

| 角色 | 可选工具 | 在练习中负责什么 |
|---|---|---|
| 协作助手 | 能操作本地文件与终端的 AI 编码工具 | 读需求、写代码、解释错误、按反馈修改 |
| 画面 | HTML / CSS / SVG / Canvas | 文字、形状、路径与简单动画 |
| 时间线与导出 | HyperFrames 或 Remotion，先选一个 | 把画面、字幕和声音组织成视频 |
| 辅助处理 | FFmpeg / ffprobe | 转码、抽帧、混音与文件检查 |

Three.js、Blender 和复杂生成工具留到需要空间表现时再用。本仓库不要求购买指定 AI 订阅，也不比较订阅档位。
